There are 2 files contained in this folder. Details of each are below.

BDF_N400_stimRT-mod.txt
This is the bin descriptor file for the task. It contains 4 bins, related/unrelated (2), correct/incorrect (2).
These are stimlus-locked bins for related and unrelated word pairs with either correct or incorrect responses 
These are also (all) followed by a response within 200 to 1500ms from stimulus onset trigger.
The bdf file also attaches the reaction time for response in the event to the end of all bins 1-4. 

PURSUEmastoidref.txt
This is a file that can be used to create a mastoid reference using channel operations for re-referencing 
offline to the average of the mastoids (T9/T10).
